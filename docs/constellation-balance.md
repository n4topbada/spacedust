# 별자리 업데이트 · 2026-09-11

사진은 기능 방향만 반영하고, 아래 수치는 사용자 위임에 따라 새로 설계했다. 장비 연구의 각각 ×2만 고정 요구사항이다.

## 장비와 성장

- 도구 14종의 기본 생산량은 기존보다 약 10~13% 감소했다. 상위 도구의 초당 생산량은 바로 아래 도구의 4배 이상이다.
- 구매가는 현재 보유 수량마다 1.185배 증가한다. 최대 보유량은 500개다.
- Lv.1~5는 보유 0·25·75·150·300개 기준이며 생산 배율은 ×1·2·4·8·16이다. 제작에 도구를 사용하면 현재 보유량에 따라 레벨도 내려간다.
- 도구의 기본 구매가 / 초당 생산량 비율은 순서대로 약 36·65·120·180·250·400·600·900·1400·2200·3500·5500·8000·12000초다. 실제 회수 시간에는 보유량·연구·별자리 배율이 반영된다.
- 성장 질량: 0 → 180 → 3K → 60K → 2M → 80M → 6B → 800B → 250T → 100Qa → 120Qi → 300Sx.
- 최종 성장 기준은 이전 500Qa의 600,000배다. 별자리 경험치와 은하가루 경험치는 별도 레벨이 아닌 누적 질량에만 추가된다.
- 12·13·14번 도구의 질량 해금은 제거했다. 각각 5·10·15세트 완성이 유일한 해금 조건이며 구매 비용은 별도다.

## 연구

- 각 도구 ×2 강화 2개: 총 28개, 둘 다 장착하면 ×4. 첫 번째는 도구 8개 보유와 기본가 ×35, 두 번째는 도구 25개 보유·첫 번째 강화 장착과 기본가 ×420이 필요하다.
- 상호작용 12개: 양쪽 도구 5개 보유 후 구매. 공급 도구 5개당 대상 생산량 +4% 또는 10개당 +6%, 최대 +300%. 실제 보유량을 기준으로 계산하며 제작 소모에도 반응한다. 비용은 대상 도구 기본가 ×60이다.
- 수동 클릭: 150K 먼지에 ×1.6, 8B에 ×1.7, 20Qa에 ×1.8. 앞 단계부터 구매하고 서로 곱해진다.
- 옛 클릭·AI 강화는 제거하고 실제 구매 비용 합계를 한 번 환급한다. 새 저장과 원본 백업으로 중복 환급을 방지한다.

## 재화 전환·상점

- 1·5·10회 전환을 지원한다. 1회 비용은 5K, 현재 단계 시작 질량의 1.2%, 현재 자동 수집 90초분 중 큰 값이다.
- Stardust·Moondust·Galaxydust·Solardust는 각각 24.5%, Spacedust는 2%다.
- 일반 가루 지급량은 (8~12) × (1 + floor(현재 단계 인덱스 / 2)), Spacedust는 1~2개다.
- 기본 먼지 누적 전환량 50K부터 확정 보상. 다음 기준은 직전 기준의 4배이며 1 + floor(이미 달성한 기준 수 / 4)개의 Spacedust를 지급한다. 여러 기준을 한 번에 넘으면 모두 지급하며 같은 기준을 중복 지급하지 않는다.
- 특수 상점 비용은 해당 가루 20 × 1.75^현재레벨을 올림한 값이다.
- Stardust: 빈도 +8%/레벨, 8레벨 제한. 기존 혜성 대기 시간을 (1 + 보너스)로 나눈다.
- Moondust: 수동 위력 +12%/레벨, 12레벨 제한. Solardust: 혜성 보상 +15%/레벨, 10레벨 제한. 모두 영구적이다.
- Spacedust 대체는 기본 꺼짐이다. 켜면 부족한 일반 특수 재화만 1:1로 대체하고 정확한 소모량을 표시한다. 기본 먼지·도구·연구는 대체할 수 없다.
- Galaxydust 5개 → 다른 일반 가루 3개. Spacedust로 교환 불가. Galaxydust 20개 → 5K, 단계 질량 1.2%, 생산 180초분 중 큰 값만큼 성장 질량 추가. 기본 먼지는 증가하지 않는다.

## 콘스텔레이션·보상

- 5개 별 × 15세트, 순차 제작 75회. 세트별 상위 도구·보조 도구·×2 연구 하나·기본 먼지·일반 특수 가루 4종을 모두 소모한다.
- 모든 제작법의 도구는 해당 제작 시점에 해금 가능한 도구로 구성했다. 뒤 세트일수록 높은 도구와 더 많은 재화가 필요하며 순환 잠금이 없다.
- 제작에 소모한 연구는 효과를 잃지만 다시 살 수 있다. 이미 장착한 두 번째 연구는 첫 번째가 소모돼도 자체 ×2 효과가 남는다.
- 별당 자동 수집 +2%, 클릭 +1%를 합산한다. 세트마다 자동 수집에 ×1.18을 추가로 곱한다.
- 별 제작 경험치는 기본 먼지 재료비의 30%, 세트 마지막 별은 250%다. 누적 질량만 증가한다.
- 세트 완성마다 럭키박스 1개. 가루 4종 묶음 55%, 기본 먼지 30%, 성장 질량 14%, Spacedust 3개 1%다. 개봉 시 상자를 차감하고 저장한다.
